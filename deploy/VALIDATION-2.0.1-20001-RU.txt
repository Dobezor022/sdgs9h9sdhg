Обязательный deployment gate:
- В среде формирования ZIP отсутствует Rust toolchain и нет доступа к registry, поэтому cargo compilation нельзя честно заявить локально.
- clean-install-2.0.1.sh ОБЯЗАТЕЛЬНО запускает cargo test --all-targets и cargo build --release --bins на Ubuntu ДО остановки текущего сервиса.
- При любой Rust compile/test ошибке production сервер не переключается.
- После переключения installer требует Rust health 2.0.1/20001 + schema 14; при ошибке выполняется rollback runtime/config.

Legacy OPAQUE/password endpoints: fail-closed by design in 2.0.1. QR/device/recovery path is the supported production path.
