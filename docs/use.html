Как пользоваться FedMes

Запуск локального сервера Windows, установка клиентов, подключение по QR и базовые проверки.

Вариант 1: постоянный сервер Ubuntu HTTPS

  1. Соберите все платформы командой Build\all.ps1.
  2. Установите сервер по инструкции Ubuntu 24.04.
  3. Получите закрытые QR-коды.
  4. Установите APK на телефоны и EXE на Windows.
  5. На каждом устройстве отсканируйте QR своего пользователя.

Вариант 2: локальный Windows HTTP сервер

Соберите windowsxhttp, затем в PowerShell:

$env:FEDMES_ADDR = "0.0.0.0:8008"
$env:FEDMES_DATA_DIR = "C:\ProgramData\FedMes"
.\Build\windowshttp\fedmes-server.exe serve

Разрешите входящий TCP 8008 в брандмауэре только для частной сети. Узнайте LAN-адрес ПК через ipconfig и выпустите QR с адресом вида http://192.168.1.108:8008 и параметром --allow-http.

Установка Android Normal

Файл находится в Build/android/normal. Установка через ADB:

adb install -r Build/android/normal/FedMes-normal-debug.apk

Установка Huawei

Файл находится в Build/android/huawei/harmonous2.0:

adb install -r Build/android/huawei/harmonous2.0/FedMes-huawei-debug.apk

Windows-клиент

Запустите Build/windowsclient/FedMes.Desktop.exe. Сборка самодостаточная и не требует отдельной установки .NET Runtime. Секреты устройства сохраняются средствами Windows DPAPI в профиле текущего пользователя.

Первое подключение

  1. Выберите подключение нового устройства.
  2. На телефоне разрешите доступ к камере; на ПК укажите QR через поддерживаемый экран подключения.
  3. Используйте QR только для указанного пользователя.
  4. Дождитесь загрузки списка чатов.
  5. Удалите PNG приглашения после успешного подключения.

Проверка доступности

curl https://ВАШ_ДОМЕН/health

Для локального Windows-сервера:

curl http://127.0.0.1:8008/health
Debug APK подписан отладочным ключом. Для внешнего распространения подготовьте собственный release keystore и release-конфигурацию подписи.
