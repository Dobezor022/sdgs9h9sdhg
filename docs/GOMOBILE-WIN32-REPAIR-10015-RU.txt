FedMes 1.0.6 build 10015 — восстановление host gomobile на Windows

Исправленная проблема:
  fork/exec ...\\gomobile.exe: %1 is not a valid Win32 application

Причина: в GOPATH/bin находился поврежденный либо собранный не для windows/amd64
файл gomobile.exe. Сборщик больше не доверяет существующему бинарнику вслепую.

Новое поведение fedmes-build:
- определяет точный GOPATH/bin/gomobile.exe;
- проверяет файл через `go version <path>` без его запуска;
- сверяет GOOS/GOARCH с платформой запущенного сборщика;
- удаляет несовместимый файл;
- ставит закрепленную версию gomobile с явными host GOOS/GOARCH и GOBIN;
- повторяет gomobile init один раз после автоматической переустановки;
- корректно заменяет GOOS/GOARCH/GOFLAGS в окружении, не оставляя дубликаты.

Криптографический код, AAR API и формат сообщений этим исправлением не меняются.
