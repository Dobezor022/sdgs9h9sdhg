Структура проекта

Проект разделён на исходный код, готовые сборки, инструменты установки и документацию.

ПутьСодержание
android/Android-приложение Kotlin/Jetpack Compose, варианты Normal и Huawei.
desktop/Windows-клиент WPF .NET 10 и модульные тесты.
server/Сервер Go, SQLite, выдача приглашений и API сообщений.
tools/Исходники программ fedmes-build, fedmes-qr и fedmes-install.
Build/Единый каталог команд сборки и готовых файлов.
deploy/Интерактивная установка Ubuntu 24.04 и примеры переменных сервера.
docs/Русская документация HTML.

Каталог Build

Build/
├── android.ps1
├── huawei.ps1
├── windowsclient.ps1
├── windowsxhttp.ps1
├── all.ps1
├── fedmes-build.exe
├── fedmes-build
├── android/
│   ├── normal/
│   └── huawei/harmonous2.0/
├── windowsclient/
├── windowshttp/
└── linuxhttps/

Build/windowshttp содержит Windows-версию серверной части, которая работает по HTTP и предназначена для локальной сети или тестов. Build/linuxhttps содержит сервер Linux, который установщик закрывает Nginx и публичным HTTPS.
