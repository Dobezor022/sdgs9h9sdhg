# FedUI 2 — закрытая дизайн-система FedMes 2.0

FedUI 2 не использует Material/Fluent как визуальный язык. Android и Windows предоставляют только системное окно/surface, GPU, ввод, IME, accessibility bridge, камеру, микрофон и secure storage. Все визуальные компоненты, размеры, состояния, навигация и иконография принадлежат FedMes.

## Принципы

- Плотная информационная компоновка без гигантских карточек и декоративного пустого пространства.
- Минимальные радиусы (обычно 0–5 logical units), чёткие разделители, стабильное расположение действий.
- Старые мессенджеры используются только как принцип плотности/предсказуемости, не как визуальный референс для копирования.
- Security State — первоклассный элемент UI (`Security Spine`, `Device Room`, `Security Center`).
- Анимация только для объяснения изменения состояния; никакой анимации ради декора.
- Один набор semantic tokens на Windows/Android; platform bridge не определяет внешний вид.
- Ввод текста использует системный IME через узкий bridge, но поле, курсор, рамка и состояния рисуются FedUI.

## Desktop

Три области: узкий Control Rail, Conversation Ledger, Conversation Workspace. Call Workspace заменяет центральную область при звонке. Device Room и Security Center являются отдельными рабочими режимами, а не скрытыми настройками.

## Mobile

Та же визуальная грамматика, но одна рабочая область за раз. Нижняя навигация не является обязательной. Устройства, безопасность и звонки доступны напрямую из верхнего уровня навигации.

## Реализация в архиве

`android/.../ui/fedui2/FedUi2.kt` содержит низкоуровневые Compose/Foundation primitives без Material widgets. `desktop/.../FedUI2/FedSurface.cs` — один custom-rendered WPF surface без Button/ListBox/TextBox. Текущий legacy UI 1.x оставлен как migration shell до переноса всех экранов; он не является целевой FedUI 2 реализацией.
