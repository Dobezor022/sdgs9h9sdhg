# Аудит FedMes 1.0.5/10012 → 1.0.6/10015

## Найденные риски

- Серверная сессия ранее могла ошибочно восприниматься как готовность расшифровывать историю.
- Новый локальный профиль мог заменять рабочий до полного восстановления.
- Старые ключи были слишком связаны с локальным Keystore/DPAPI профилем.
- QR требовал устойчивой идемпотентности после COMMIT и потери ответа.
- Не было отдельного Recovery Key и server-side encrypted vault.

## Закрыто в 10015

- Auth state и key state разделены.
- Добавлены ARK, encrypted vault, Recovery Key package, staged commit и access verifier.
- QR protocol v3 выполняется атомарно и возвращает сохранённый результат повторного запроса.
- Добавлены безопасные backup/verify/restore scripts.

## Остаётся

- OPAQUE.
- Проверенный ratchet-протокол.
- Полная FMK migration.
- Сквозной подписанный device approval во всех клиентах.
