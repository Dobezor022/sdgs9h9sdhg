Установка Ubuntu 24.04 с HTTPS

Интерактивный установщик создаёт отдельного системного пользователя, systemd-сервис, Nginx, сертификат Let’s Encrypt и закрываемую паролем страницу загрузок.

До установки

  1. Подготовьте чистый сервер Ubuntu 24.04 x64.
  2. Создайте DNS A-запись домена на IPv4 сервера. AAAA-запись добавляйте только при рабочем IPv6.
  3. Разрешите входящие TCP 22, 80 и 443 в панели VPS.
  4. Соберите linuxhttps, APK и Windows-клиент на рабочем ПК.
  5. Скопируйте весь проект на сервер, например в /opt/src/fedmes.

Одна команда

cd /opt/src/fedmes
sudo bash deploy/install.sh

Установщик спросит домен, email для сертификата, внутренний порт, пути к APK/EXE, необходимость пароля страницы загрузок и выпуск QR-кодов.

Что устанавливается

ПутьНазначение
/opt/fedmes/binСервер и QR-программа.
/var/lib/fedmesSQLite, медиа и закрытые QR; владелец fedmes.
/etc/fedmes/fedmes.envПеременные systemd.
/var/www/fedmesСтраница и клиентские файлы.
/etc/nginx/sites-available/fedmesОбратный прокси HTTPS.

Проверка

sudo systemctl status fedmes --no-pager
sudo nginx -t
curl -fsS https://ВАШ_ДОМЕН/health
sudo journalctl -u fedmes -n 100 --no-pager

Повторная установка и обновление

Повторный запуск сохраняет каталог /var/lib/fedmes, заменяет серверные бинарные файлы, обновляет systemd/Nginx и повторно проверяет HTTPS. Перед крупным обновлением сделайте резервную копию.

DNS обязателен. Certbot не выпустит сертификат, пока домен не ведёт на сервер и порты 80/443 недоступны из Интернета.
