FedMes 1.0.6 build 10015 — исправление проверки платформы gomobile

Проблема:
  go version <путь-к-exe>
выводит версию Go, которой собран бинарник, например:
  gomobile.exe: go1.26.2
Команда не обязана выводить windows/amd64, поэтому прежний сборщик ошибочно
отклонял исправный gomobile.exe.

Исправление:
- fedmes-build читает встроенную информацию бинарника напрямую через
  стандартный пакет debug/buildinfo;
- проверяются настройки GOOS и GOARCH, записанные в бинарнике;
- файл не запускается во время проверки;
- ожидаемая цель на Windows x64: windows/amd64;
- Repair-Gomobile.ps1 использует структурированный вывод
  `go version -m -json` и проверяет Settings.GOOS/Settings.GOARCH.

Криптографический код, AAR API, OPAQUE, Olm/Megolm и формат сообщений не менялись.
