Документация FedMes

Сборка Android, Huawei, Windows и Linux, установка сервера Ubuntu 24.04 с HTTPS, выпуск QR-кодов и эксплуатация.

Структура проектаГде находятся исходники, сборки, инструменты и установщик. АрхитектураКлиенты, сервер, хранилище, QR и HTTPS-шлюз. ИспользованиеЗапуск, установка клиентов и первое подключение. СборкаКоманды Windows PowerShell и единая Go-программа для Windows/Linux. Ubuntu 24.04 + HTTPSПодготовка домена и интерактивная установка одной командой. QR-кодыПодключение пяти фиксированных пользователей без публикации секретов. ОбслуживаниеЖурналы, обновление, резервное копирование и восстановление. БезопасностьПрава файлов, HTTPS, закрытые QR и правила эксплуатации.

Назначение

FedMes — закрытый семейный мессенджер. В проект входят сервер на Go, Android-клиент на Kotlin/Jetpack Compose с вариантами Normal и Huawei, Windows-клиент WPF на .NET и инструменты сборки/развёртывания.

Быстрый маршрут

  1. На рабочем ПК откройте docs/build.html и соберите нужные платформы.
  2. Передайте проект или каталог Build на Ubuntu 24.04.
  3. Настройте DNS домена на IP сервера и откройте TCP 80/443.
  4. Выполните sudo bash deploy/install.sh.
  5. Получите QR-коды из закрытого каталога, подключите устройства и удалите QR-файлы.
Важно. Каталог Build содержит готовые программы. Каталоги android, desktop, server и tools содержат исходный код.
Документация относится к исходному проекту и программам, находящимся в этом архиве.
