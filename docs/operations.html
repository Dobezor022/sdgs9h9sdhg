Обслуживание сервера

Основные команды для журнала, обновления, резервного копирования и восстановления.

Управление службой

sudo systemctl status fedmes
sudo systemctl restart fedmes
sudo systemctl stop fedmes
sudo systemctl start fedmes
sudo journalctl -u fedmes -f

Проверка HTTPS и Nginx

sudo nginx -t
sudo systemctl reload nginx
sudo certbot renew --dry-run
curl -fsS https://ВАШ_ДОМЕН/health

Резервная копия

Для согласованной копии остановите сервер:

sudo systemctl stop fedmes
sudo tar --xattrs --acls -C /var/lib -czf "/root/fedmes-backup-$(date +%F-%H%M%S).tar.gz" fedmes
sudo systemctl start fedmes

Восстановление

sudo systemctl stop fedmes
sudo mv /var/lib/fedmes /var/lib/fedmes.before-restore
sudo tar -C /var/lib -xzf /root/fedmes-backup-ДАТА.tar.gz
sudo chown -R fedmes:fedmes /var/lib/fedmes
sudo chmod 700 /var/lib/fedmes
sudo systemctl start fedmes

Обновление программ

  1. Соберите новый Build/linuxhttps.
  2. Передайте обновлённый проект на VPS.
  3. Сделайте резервную копию.
  4. Повторно выполните sudo bash deploy/install.sh.
  5. Проверьте журнал и /health.

Удаление

sudo systemctl disable --now fedmes
sudo rm -f /etc/systemd/system/fedmes.service
sudo systemctl daemon-reload
sudo rm -rf /opt/fedmes /etc/fedmes
sudo rm -f /etc/nginx/sites-enabled/fedmes /etc/nginx/sites-available/fedmes
sudo nginx -t && sudo systemctl reload nginx
Каталог /var/lib/fedmes не удаляйте, пока не сделана и не проверена резервная копия.
