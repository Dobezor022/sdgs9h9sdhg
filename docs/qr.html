QR-коды подключения

QR содержит одноразовый секрет. Его создают рядом с той же базой данных, которую использует сервер.

Windows

Сначала соберите windowsxhttp. Затем:

.\Build\windowshttp\fedmes-qr.exe `
  --server-url "http://192.168.1.108:8008" `
  --data-dir "C:\ProgramData\FedMes" `
  --out-dir ".\FedMes-QR" `
  --ttl "30m" `
  --users all `
  --allow-http `
  --server-exe ".\Build\windowshttp\fedmes-server.exe"

Linux после установки

sudo -u fedmes /opt/fedmes/bin/fedmes-qr \
  --server-url "https://chat.example.ru" \
  --data-dir "/var/lib/fedmes" \
  --out-dir "/var/lib/fedmes/private-qr" \
  --ttl "30m" \
  --users all \
  --server-exe "/opt/fedmes/bin/fedmes-server"

Отдельные пользователи

--users grisha,papa,mama

Допустимы только grisha, papa, mama, yura, vasya.

Обновление QR

Программа по умолчанию не перезаписывает существующие PNG. Используйте новый каталог либо добавьте --replace. Старый одноразовый код после применения повторно не работает; неиспользованные коды прекращают действовать после TTL.

Не публикуйте QR. QR-коды нельзя помещать в /var/www/fedmes, отправлять в общие чаты или хранить после подключения устройства.
