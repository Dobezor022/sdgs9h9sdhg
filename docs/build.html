Сборка проекта

Команды записывают результат только в стандартизированные подкаталоги Build.

Требования Windows

  • Windows 10/11 x64.
  • Go 1.25 или новее для сервера.
  • JDK 21 и Android SDK для APK.
  • .NET SDK 10 для Windows-клиента.
  • PowerShell 5.1 или PowerShell 7.

Windows PowerShell

Откройте PowerShell в корне проекта:

Set-Location C:\Users\STUDIO-PC\Pictures\androidconsole
Что собратьКоманда
Android Normalpowershell -ExecutionPolicy Bypass -File .\Build\android.ps1
Huaweipowershell -ExecutionPolicy Bypass -File .\Build\huawei.ps1
Windows-клиентpowershell -ExecutionPolicy Bypass -File .\Build\windowsclient.ps1
Windows HTTP серверpowershell -ExecutionPolicy Bypass -File .\Build\windowsxhttp.ps1
Всёpowershell -ExecutionPolicy Bypass -File .\Build\all.ps1

Для пропуска тестов добавьте -SkipTests.

Единая программа Windows

.\Build\fedmes-build.exe android
.\Build\fedmes-build.exe huawei
.\Build\fedmes-build.exe windowsclient
.\Build\fedmes-build.exe windowsxhttp
.\Build\fedmes-build.exe linuxhttps
.\Build\fedmes-build.exe all

Без аргументов программа показывает интерактивное меню:

.\Build\fedmes-build.exe

Ubuntu/Linux

chmod +x Build/fedmes-build
./Build/fedmes-build android
./Build/fedmes-build huawei
./Build/fedmes-build windowsclient
./Build/fedmes-build linuxhttps
./Build/fedmes-build all
Сборка Windows WPF на Linux выполняется через Windows targeting pack .NET. Наиболее надёжный вариант для Windows-клиента — запуск windowsclient.ps1 на Windows.
