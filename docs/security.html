Безопасность

Минимальные правила, обязательные для семейного сервера и одноразовых приглашений.

Сетевая модель

  • Сервер Go слушает только 127.0.0.1:8008.
  • Публичный доступ проходит через Nginx по HTTPS 443.
  • HTTP 80 используется для выпуска сертификата и перенаправляется на HTTPS.
  • Не открывайте порт 8008 в облачном firewall.

Файлы и права

  • /var/lib/fedmes имеет права 0700 и принадлежит пользователю fedmes.
  • QR-коды находятся вне публичного web-каталога.
  • Конфигурация systemd недоступна обычным пользователям на запись.
  • Страница загрузок может быть закрыта отдельным логином и паролем.

systemd-изоляция

Сервис запускается без root с NoNewPrivileges, защитой системных каталогов, закрытым домашним каталогом и единственным разрешённым каталогом записи /var/lib/fedmes.

Эксплуатационные правила

  1. Регулярно устанавливайте обновления Ubuntu.
  2. Используйте SSH-ключи и запретите парольный вход root.
  3. Храните резервные копии отдельно от VPS.
  4. Удаляйте QR-файлы сразу после подключения устройств.
  5. Не размещайте базу SQLite, логи или QR в каталоге загрузок.
  6. Проверяйте контрольные суммы перед переносом бинарных файлов.
Установщик не публикует базу, медиа и QR. В web-каталог копируются только выбранные APK и EXE.
