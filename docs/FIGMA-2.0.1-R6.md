# FedMes 2.0.1 R6 — Figma

Design file: https://www.figma.com/design/TScw6uOtnCh3SmSeqzyaj2

## Frames

- `00 Foundations` — FedUI 2 colors and visual principles.
- `01 Mobile — Chats Empty` — first-run empty chats, search, overflow menu, Chats/Settings navigation.
- `02 Mobile — Conversation` — conversation, text bubbles, circle and square video-message states, composer.
- `03 Mobile — Settings` — profile and major settings groups.
- `04 Windows — Messenger` — sidebar, search, chat rows, conversation workspace and composer.
- `05 Windows — QR Sign In` — QR, waiting state, retry and cancel actions.

The implementation intentionally uses FedUI 2 as the visual language. Material/Fluent may remain as platform/runtime primitives in legacy code, but they are not the design reference.
