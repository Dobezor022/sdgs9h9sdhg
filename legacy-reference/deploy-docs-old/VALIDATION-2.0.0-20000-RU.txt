IMPORTANT PRODUCTION GATES
==========================
1. FSA2 message engines exist on Android/Windows, but legacy MessagingRepository
   is not yet fully cut over. Until that cutover, this is not an all-FSA2 client.
2. Realtime cryptography and blind streaming transports exist, but complete
   Android/Windows microphone/camera/codec/render call engines and call UI are
   not finished in this package.
3. FedUI2 foundations exist on both platforms, but the complete existing UI is
   still a migration shell and has not been fully rewritten onto FedUI2.
4. Full device-admission/recovery UX and Trust Constellation persistence/cross-
   device checkpoint integration require final application wiring.
5. Android/Windows/server release builds must pass on supported target toolchains.
6. Production packages must be signed. Production signing keys are intentionally
   not included in this archive.
7. Current cross-platform bridge serializes some FSA2 private key material as
   process-local JSON/base64 strings during creation/import. Before final rollout,
   root/device long-lived private keys must be moved behind non-exportable/handle-
   based endpoint vault APIs so normal UI/application code never receives them.
8. The current conversation ratchet requires in-order delivery for one route. The
   final multi-path implementation must either enforce one authenticated ordered
   lane per ratchet or add a bounded skipped-key/out-of-order receive mechanism.
9. Parser fuzzing, call soak/network-loss tests, migration on a production-data
   copy, rollback/fork tests and independent security review remain mandatory.

CONCLUSION
==========
This archive is a real FedMes 2.0 production-source candidate with implemented
new security/transport foundations and rebuilt tooling. It is NOT represented as
an audited/signed/deploy-ready production release. That label is reserved until
all gates above pass.
